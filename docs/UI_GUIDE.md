# UI 디자인 가이드 — 내 월급 생존 가능 지역 테스트

# 디자인 원칙

## 핵심 방향
게임처럼 보이면 안 된다.

느낌은:

토스 실험실 기능
+
생활비 시뮬레이터
+
밈 테스트

사이 어딘가.

---

# 목표 UX

사용자는:
1. 월급 입력
2. 몇 개 선택
3. 결과 확인
4. 공유

까지 20초 안에 끝나야 한다.

---

# 디자인 키워드

- 절제된
- 현실적인
- 공감 가는
- 금융 서비스 같은
- 빠른
- 가볍게 웃긴

# 입력 화면

## 구성

### 1. 월급 입력
- 숫자 입력
- 실시간 포맷팅
- "만원" suffix

예시:
320

---

### 2. 소비 성향 선택

카드형 버튼:

[절약형]
[보통형]
[플렉스형]

선택 시:
- border 강조
- 배경 살짝 밝게

---

### 3. 주거 스타일 선택

세그먼트 느낌.

---

### 4. 차량 여부

토글 버튼.

---

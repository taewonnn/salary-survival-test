# PRD: 내 월급 생존 가능 지역 테스트

## 목표
앱인토스 안에서:
- 짧고
- 결과가 즉시 나오며
- 공유하기 쉽고
- 반복 테스트 가능한

금융 기반 밈형 소비/생활 시뮬레이터 제공.

사용자는 자신의 월급과 소비 성향을 입력하고,
“어느 지역에서 얼마나 생존 가능한지”를 재밌게 확인할 수 있다.

---

# 1. 사용자

## 메인 타겟
- 20~30대 직장인
- 월급 관리에 관심 있는 사용자
- 소비/재테크 콘텐츠 좋아하는 사용자
- 토스 앱 사용자

## 기대 행동
- 자신의 월급 입력
- 소비 성향 선택
- 결과 확인
- 친구 공유
- 반복 테스트

---

# 2. 핵심 컨셉

정확한 부동산 계산기가 아니라:

> "내 월급으로 어디까지 버틸 수 있을까?"

를 재밌게 보여주는
“금융 밈 시뮬레이터”.

핵심은:
- 현실 공감
- 짧은 재미
- 공유성
- 반복 테스트

---

# 3. 핵심 기능

## 3-1. 월급 입력
사용자 입력:
- 세후 월급

예시:
- 240만원
- 320만원
- 500만원

입력 방식:
- 숫자 입력
- 슬라이더 선택 가능

---

## 3-2. 소비 성향 선택

### 옵션
- 절약형
- 보통형
- 플렉스형

### 계산 반영
| 유형 | 배수 |
|---|---|
| 절약형 | 0.8 |
| 보통형 | 1.0 |
| 플렉스형 | 1.35 |

---

## 3-3. 주거 스타일 선택

### 옵션
- 원룸
- 오피스텔
- 신축/역세권

### 추가 비용
| 유형 | 추가 비용 |
|---|---|
| 원룸 | 0 |
| 오피스텔 | +35만원 |
| 신축/역세권 | +60만원 |

---

## 3-4. 차량 여부

### 옵션
- 없음
- 있음

### 계산
- 차량 있음: +40만원

---

# 4. 지역별 생활비 데이터

## 기본 지역 데이터
| 지역 | 기준 생활비 |
|---|---|
| 강남 | 320만원 |
| 성수 | 280만원 |
| 잠실 | 260만원 |
| 마포 | 240만원 |
| 수원 | 180만원 |
| 부산 | 170만원 |
| 대구 | 160만원 |

※ MVP 단계에서는 하드코딩.

---

# 5. 계산 방식

## 최종 월 소비 계산

totalMonthlyCost =
(지역 기본 생활비 × 소비성향 배수)
+ 주거 추가비용
+ 차량 비용

## 생존 점수 계산

survivalScore =
월급 / totalMonthlyCost

---

# 6. 결과 시스템

## 결과 등급

| 점수 | 결과 |
|---|---|
| 1.5 이상 | 왕처럼 가능 👑 |
| 1.2 이상 | 여유롭게 가능 👍 |
| 1.0 이상 | 무난하게 생존 가능 |
| 0.8 이상 | 통장 잔고 위험 ⚠️ |
| 0.6 이상 | 배달앱 삭제 권장 |
| 0.6 미만 | 강남은 다음 생에... |
